対応
仕様: コードチャンネル選択で周波数を上書き。割り当てコードは変更可能。
割当: A=最高音 / B=2番目 / C=3番目 / D=最低音（ハイ→ロー）。
ショートカット: コードチャンネルは 0〜9。オクターブは A=C2 / S=C3 / D=C4 / F=C5。/ Space=PLAY・STOP。

演奏録音（シーケンサー）

4/4
トラック 0 / 6
パターンを数字テキストで保存／復元（コピペして後日読込可）
入力: セルをクリックして選択 → 数字キーで記録。
・コード: チャンネル 0〜9（4音和音）　・単音: 1〜9（Cメジャー音階・ベース/旋律はオクターブで調整）
・ドラム: 1キック 2スネア 3ハット 4オープンハット 5タム 6クラップ
前音を伸ばす（タイ）は - キーで「−」を入力。 休符は . / Backspace / 同じセル再クリックでトグル。 矢印キーで移動。
各トラックで種別・音色・オクターブ・音符の長さ（全音符／二分音符／四分音符／八分音符）を選択。マスの幅＝音の長さ（全音符は1小節ぶん、八分音符の8倍幅）。
※音色はメイン画面で作った A/B/C/D（波形・フィルタ・変調・音量）を使用。コードは4音にA〜Dを割当、単音はトラックで選んだ音色で発音。
出力小節: 再生とWAV出力に使う長さを 1小節のみ／1〜2／1〜3／1〜4小節 から選べます（範囲外の小節は薄く表示）。
WAV出力: 現在のパターンを1ループ分、無圧縮の音声ファイル（.wav）として書き出します（一瞬で完了）。
M4A出力: 同じ内容を圧縮して .m4a（AAC 128kbps・WAVの約1/10のサイズ）で書き出します。ブラウザ内蔵のエンコーダを使うため曲の長さぶん時間がかかり、その間ボタンに残り秒数が出ます（書き出し中は無音）。AAC非対応のブラウザ（Firefox等）では .webm で保存されます。

説明

使い方
PLAY を押すと発音（Space で PLAY/STOP 切替）。
音色は4つ（高音から A / B / C / D）。
コードチャンネルで和音（コード）を変更（ショートカット：0〜9）。
オクターブで全体の高さを一括変更（ショートカット：A/S/D/F）。
各音色は 周波数で音程、波形 / フィルタで音色変化。
変調（量）/ 変調 速度でビブラート調整。
コードを選び、音色を変えつつ全体バランスを調整するなど。
コードチャンネルを切り替えながら簡易演奏が可能。
いい感じのコードをコードチャンネルに割り当てるといい感じになる。
